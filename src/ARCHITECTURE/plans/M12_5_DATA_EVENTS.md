## 目標與工作邊界

DATA-01 負責取得及驗證價格來源；本工作負責讓來源、交易日、停牌、五類企業行動審核及執行模型共同滿足研究條件。先驗收開發期及暖機，再驗證期，最後歷史評估期；每一期各有獨立狀態。

基線問題包含 55 筆分項覆蓋審核與 56 筆企業行動待核對，不一定代表 55 個文件或 56 個獨立事件。按 `(symbol,event_date,event_kind)` 去重、保留相依與來源，不能以原始錯誤筆數當人工完成率。

## 先定義的契約

| 契約 | 必要內容 |
| --- | --- |
| `EventReview` | 標的、事件種類／生效日、公告可得日、來源／證據 hash、是否支援、審核結果、尚缺欄位 |
| `CoverageReview` | 沿用 symbol/start/end/category/source/evidence；五類分開、日期連續；真實審核後才填寫 |
| `CorporateActionCapability` | 支援的事件種類、所需欄位、股數／成本／現金／權利變動、可支用日與資訊時間規則 |
| `PeriodAcceptance` | input／readiness fingerprint、證據集合、通過／未解項目、人工審核紀錄及驗收時間 |

若調查確認需要認股權、增資或減資模型，先寫事件例題與處理契約。缺認購價格、數量、期限、資金支用日或權利價值時，保留 unknown／blocked，不用價格跳動反推配股率來解除阻擋。

## 驗收矩陣

| 案例 ID | 情境 | 通過標準 |
| --- | --- | --- |
| E-A01 | 某月已匯入但一日缺價 | 若沒有核對過的停牌／休市依據，該期仍被阻擋 |
| E-A02 | 五類審核少一類或中間一天斷層 | 研究與暖機窗口都必須完整；不能用其他類別或舊 coverage 補足 |
| E-A03 | 有來源的停牌 | open 保持不可交易，估值可按已定義規則延續；不得製造 volume／成交 |
| E-A04 | 同日股票股利／拆股加現金股利 | 按事件前股數計算現金，再調整股數、成本與止損價格；與手算一致 |
| E-A05 | 拆股與 forward-return 序列 | 已還原 raw 價格遭拒；生效後事件不能改變此前訊號／報酬 |
| E-A06 | 未建模權利或必要欄位未知 | 明確列出尚缺欄位與受影響期；不輸出相依策略及基準績效 |
| E-A07 | 新支援事件 | 股數、現金、成本、權利與 NAV 符合事件契約；資訊與款項不早於其可得／可用日 |
| E-A08 | 每期暖機與來源完整性 | 至少 max(120,設定暖機) 個經核對 session，必要檢查無 unknown／blocking；全來源 hash 可驗證 |
| E-A09 | 新凍結與舊資料並存 | 新 study ID 可追溯全部證據；舊 study/report 的 bytes、hash 與驗證結果維持可核對 |
| E-A10 | 改股票池／期間以避免未解問題 | 必須另建協議與 study ID，記錄原因及資料接觸；不得在原研究中悄悄刪股 |
| E-A11 | 僅 A 批完成，B／C 尚缺 | 只驗收實際已符合條件的開發期；其他期清楚受阻，不將局部完成報成整案通過 |

事件數值使用已定義 rounding／成本規則後與手算比較；數量／日期精確一致，現金與 NAV 容忍 `abs(a-b) <= 1e-6 + 1e-12 * max(abs(a),abs(b))` TWD。拒絕非有限值；價格一致性沿用來源所需精度與具名規則，不能靠加大容忍度掩蓋不符。
